# Endless background

Replaces the basic gradient background in air theme with an image.

## Swapping the image
Replace `assets/background.jpg`, keeping the filename — it's referenced
in `about.json` as the `bg` asset.

## Adjusting the overlay
The dark wash in `common/common.scss` keeps text legible. Bump the 0.45
alpha up for busier photos, down for muted ones.
